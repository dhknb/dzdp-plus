# 大众点评 Plus - 高并发本地生活服务平台

## 项目简介

这是一个基于 SpringBoot 3 的高并发本地生活服务平台，涵盖商户浏览、优惠券秒杀、达人探店、社交互动等核心业务场景。项目聚焦于解决高并发场景下的稳定性、一致性与可扩展性问题。

## 核心功能

### 业务功能模块

- **用户认证：** 基于 Redis 实现分布式会话管理，支持短信验证码登录
- **商户服务：** 商户信息查询、附近商户搜索（Redis GEO）、商户缓存优化
- **优惠券系统：** 优惠券浏览、秒杀抢购、订单管理、取消与退款
- **社交功能：** 用户关注、好友动态、达人探店、点赞排行
- **数据统计：** 用户签到（BitMap）、UV统计（HyperLogLog）、每日Top买家排行

## 快速开始

### 环境要求

- JDK 17+
- Maven 3.8+
- MySQL 8.0+
- Redis 7.0+
- Kafka 3.x

### 启动步骤

1. **准备数据库**
```bash
# 创建数据库并导入SQL脚本
mysql -u root -p < sql/init.sql
```

2. **配置Redis**
```bash
# 启动Redis服务
redis-server
```

3. **配置Kafka**
```bash
# 启动Zookeeper
bin/zookeeper-server-start.sh config/zookeeper.properties

# 启动Kafka
bin/kafka-server-start.sh config/server.properties
```

4. **修改配置文件**
```yaml
# application.yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/dzdp?useSSL=false
    username: your_username
    password: your_password
  redis:
    host: localhost
    port: 6379
```

5. **启动后端服务**
```bash
mvn clean install
cd dzdp-core-service
mvn spring-boot:run
```

6. **启动前端项目**
```bash
cd dzdp-vue3
npm install
npm run dev
```

## 核心问题与解决方案

### 1. 缓存穿透与击穿

**问题：** 恶意请求或热点数据失效导致大量请求打到数据库

**解决方案：**
- 布隆过滤器前置拦截非法请求
- 空值缓存避免重复查询不存在的数据
- 本地缓存 + Redis 双层防护
- 双重锁检测避免并发重建
- 逻辑过期 + 异步重建削峰填谷

### 2. 秒杀超卖与库存一致性

**问题：** 高并发下库存扣减不准确，Redis与数据库数据不一致

**解决方案：**
- Lua脚本原子扣减
- 乐观锁防止超卖
- 本地消息表保证最终一致性
- 订单对账日志定期校验
- 补偿队列自动修复差异

### 3. 消息可靠性

**问题：** MQ宕机、消息丢失、重复消费、消费延迟

**解决方案：**
- 生产端发布确认机制
- 指数退避重试策略
- 消费端幂等处理
- 死信队列隔离异常消息
- 延迟队列支持定时任务

### 4. 流量控制

**问题：** 突发流量冲击系统，服务不稳定

**解决方案：**
- 令牌前置授权，资格预审
- 令牌桶限流，平滑流量曲线
- 多维度限流（IP/用户/接口/活动）
- 优先级配额（VIP用户）
- 动态限流阈值调整

### 5. 分库分表

**问题：** 单表数据量大，查询性能下降

**解决方案：**
- 按用户ID路由分片
- 雪花算法生成全局唯一ID
- 分片内对账保证一致性
- 订单路由表快速定位
- 跨分片聚合查询优化
